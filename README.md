# BoltPass

BoltPass started out as my A-Level Computer Science NEA (Non-Examinable Assessment) project, but I have continued development after the fact out of interest in cybersecurity and encryption. 

It is a simple password manager that makes use of AES-256 encryption alongside PBKDF2 (with 100000 iterations as standard) to encrypt users' passwords. It provides functionality such as email verification, password changing and 2 factor authentication using time-based one-time passcode (TOTP).
